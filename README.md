# 👋 Monesh Chaudhari — Personal Portfolio

A modern and interactive **personal portfolio website** built with **Python and Streamlit** to showcase my education, technical skills, projects, certifications, and contact information.


## 📌 About the Project

This project is my personal portfolio website created using **Streamlit**. It provides a simple and interactive way to present my academic background, technical skills, projects, certifications, and professional contact information.

The portfolio is designed with a clean and responsive layout using Streamlit's columns, containers, forms, and navigation features.

* 👋 Interactive Home Page
* 🙋 About Me section
* 💻 Technical Skills section
* 📊 Featured Projects
* 🎓 Education details
